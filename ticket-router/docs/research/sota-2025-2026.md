# Retrieval and decision techniques, 2025–2026 vs the 2024 baseline

Baseline (B-2024) = LinkedIn KG-RAG (see `linkedin-kg-rag.md`): a section tree per ticket; title-similarity and explicit
links; dense-only scoring summed over sections; the LLM writes Cypher; GPT-4 answers; text fallback.

## What changed, by stage, with evidence

| Stage | 2024 baseline | 2025–26 practice | Evidence | Adopt? |
|---|---|---|---|---|
| Lexical retrieval | none (dense only) | **BM25 first-class**, often the primary ranker | *BM25 Wins at Scale* (2607.26497): BM25 leads above ~10M corpus tokens, by ~20 pts at full scale; graph RAG hits construction limits | **Yes**, primary |
| Dense retrieval | E5/BERT | Qwen3-Embedding, BGE-M3 (dense + sparse + multi-vector in one model), EmbeddingGemma; Nemotron/zembed claims are vendor-reported | MTEB snapshots (vendor blogs, check the live board) | Yes, second signal |
| Chunk/record context | section split | **Contextual retrieval**: prepend generated context to each chunk before embedding and BM25 | Anthropic: top-20 failure rate 5.7% → 2.9% (contextual emb. + BM25) → 1.9% with rerank (−67%); ECIR 2025 confirms quality, at a compute cost | **Yes**, via cards |
| Reranking | none | cross-encoder or LLM reranker after hybrid fusion | Anthropic (above); 7B ablation: reranking gives a significant gain | **Yes** |
| Agentic retrieval | single shot | iterative search with decomposition and re-retrieval on failure, **bounded** | 7B ablation (2606.21553): 2 rounds capture 95% of the gain of 5. BM25-at-scale: agent + BM25 36.9 → 69.4; "agentic reasoning works best *after* ranked discovery, not instead of it"; the agent alone used 39× the tokens | **Yes**, on top of hybrid, max 2 rounds |
| Graph | LLM-free tree + similarity edges | LightRAG / HippoRAG 2 / LazyGraphRAG / KET-RAG (LLM-built graphs, cheaper variants) | GraphRAG-Bench (ICLR 2026): graphs help multi-hop and complex reasoning, often **lose on simple tasks**; LLM graph builds are costly (LightRAG super-linear; MS-GraphRAG ~$10k per 100k docs); HippoRAG 2 linear, denser graphs better | **Deterministic graph only** (from fields + controlled vocabulary). No LLM-built graph |
| Temporal facts | none | bi-temporal edges (Zep/Graphiti) | Zep paper; memory benchmarks are vendor-reported | **Yes**, the idea |
| Context management | stuff the retrieved text | **Context engineering**: progressive disclosure (Agent Skills, Oct 2025), just-in-time loading by identifiers, deferred tool loading | Anthropic guidance; caveat: metadata quality decides what the agent can find | **Yes**, maps to L0/L1/L2 |
| Long context / CAG | n/a | cache the stable corpus in context | Long context beat RAG 73.1% vs 65.4% at ~26× token cost (secondary source); "context rot" across 18 models (Chroma) | Only for a small stable L0 prefix (prompt caching on the cloud POC) |
| Query → data | LLM writes Cypher | **typed tools** (MCP standard); text-to-query only behind validation | MCP adoption; small-model reliability | **Typed tools** |
| LLM role in routing | answer generator | (a) **feature augmenter** (normalise/enrich) + calibrated ensemble; (b) **fine-tuned small reasoning LLM** as decider | Banking SDS 2026: LLM views as augmenters, 78% on a 6-month drift set, ECE 0.036. LIA (2601.01780): SFT of R1-Distill-Llama-8B, Hit@1 +187.8% vs base, up to +211% vs SOTA assigners | (a) now; (b) phase 2 |
| Ranking robustness | n/a | permutation-invariant listwise ranking; self-calibrated listwise scores | InvariRank (SIGIR '26), SCaLR (2411.04602) | **Yes**: shuffle candidate order, check agreement |
| Abstention | none | **conformal abstention**: set the threshold on a labelled calibration set for a target error | 2405.01563; 2026 conformal-LLM survey | **Yes** |
| Search-agent training | n/a | RL-trained search agents (Search-R1, ZeroSearch…) | COLM 2025; 3B–7B Qwen bases | Research only, not v1 |

## Takeaways
1. Hybrid ranking (BM25 + dense + rerank) is the backbone. Agents refine it; they don't replace it.
2. Enrich records before indexing (contextual cards). This is the cheapest large win.
3. A graph is worth having for relations and time. LLM-generated graphs are not worth the cost here.
4. Keep agent loops short and budgeted: two rounds.
5. Use the LLM for normalisation and judgement. Calibrate it and let it abstain.
6. Our own decision logs become training data. A fine-tuned small decider is the 2026-standard upgrade.
